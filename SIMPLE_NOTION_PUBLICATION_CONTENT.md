Official destination: https://joplinapp.org/

Comparison scope: Native desktop personal notebook and note capture/editing. No custom database, plugin or server is needed for this documented local flow. Markdown and optional sync require separate learning/setup; this is not Notion database, team-workspace or migration parity.

Pricing: Free core desktop notes; optional paid Joplin Cloud synchronization and sharing plans have separate limits.

Trade-offs: Compare personal notebook/Markdown notes. Migration and multi-device synchronization need separate setup; paid Cloud services have plan limits. No complete Notion database or team-workspace parity is established.

Constraint fit: Focused Note Taking; No Database Required; Minimal Setup. This is documented basic note capture/editing/organization without a user-configured structured database or mandatory plugin/server. It is not an internal-storage claim or a measured ease/speed comparison.

## Simplenote

Text notes with tags and automatic account-based synchronization; no file attachments.

Official destination: https://simplenote.com/

Comparison scope: Personal text-note editing and tag organization in the official desktop app after account signup. No custom database, plugin or server deployment is required for this documented flow. Signup/email verification and service connectivity are setup prerequisites; this does not promise local-only operation or Notion parity.

Pricing: Free note application and synchronization service.

Trade-offs: Account and email verification required. Notes sync to the service and are not encrypted at rest; attachments are unsupported. Offline editing requires prior sign-in/download. No full Notion parity.

Constraint fit: Focused Note Taking; No Database Required; Minimal Setup. This is documented basic note capture/editing/organization without a user-configured structured database or mandatory plugin/server. It is not an internal-storage claim or a measured ease/speed comparison.

Account requirement: an account and email verification are required. No Account Required is verified false. Free Core Use is verified true.
