## Proposed route

Offline Notion Alternatives

Personal offline notes and locally available organized content in installed native workspaces. Compare AFFiNE desktop documents and whiteboards, Anytype local objects, and AppFlowy native offline mode. Notion also supports prepared offline pages in desktop/mobile apps. Cloud sync, hosted imports, remote attachments and collaboration have separate requirements. This does not guarantee complete Notion parity or full cloud-content availability offline.

Exactly AFFiNE, Anytype, AppFlowy, in that order, each with novelty score zero. Obsidian is not a member of this scoped route. No other route is approved.

## AFFiNE

An open-source, local-first workspace combining documents, databases, whiteboards, and optional cloud and AI services.

Official CTA: https://affine.pro/

- works-offline: true
- pricing-model: Free local editor and Cloud Basic; paid Cloud plans, an AI add-on and a one-time Believer offer have separate terms. The editor is MIT-licensed; the EE backend has separate authorization requirements for modification, compilation or redistribution. Check current plan prices and limits.
- trade-off-summary: Native desktop local content is the offline comparison scope. Desktop and mobile feature coverage differs; Cloud sync and collaboration require connectivity. Notion HTML/Markdown import is supported but not all features map one-to-one; review converted content. Editor and EE backend licensing differ.

Scope: Personal offline note and object organization only. Native desktop local documents, databases and whiteboards after installation. Cloud synchronization needs connectivity; mobile and browser parity are not established. No guarantee of full Notion feature, team or migration parity.


## Anytype

A local-first, offline-first workspace built around device-owned data and peer-to-peer sync.

Official CTA: https://anytype.io/

- works-offline: true
- pricing-model: A Free tier and paid membership plans are available. Paid plans expand remote storage, shared-channel and ANY ID entitlements. Check current plan prices and limits; self-hosted configurations and renewals have separate terms.
- trade-off-summary: Scope is personal notes and objects stored on the device, not full Notion parity. Normal local-first mode works offline and syncs when connected. Optional local-only mode is experimental and requires manual backups, with multi-device sync limited to the local network. Notion imports can lose feature semantics, links or files and need review.

Scope: Personal offline note and object organization only. Anytype local-first personal spaces after initial setup; synchronization and Notion import need connectivity. No guarantee of full Notion feature, team or migration parity. Local-only is a separate experimental mode with manual backup responsibility.


## AppFlowy

An open-source Notion alternative with local desktop use, offline mode, and self-hostable cloud infrastructure.

Official CTA: https://appflowy.io/

- works-offline: true
- pricing-model: Free Personal Cloud plan with storage, upload and history limits; Pro is a renewing subscription billed per workspace member. Cloud plans and self-hosted terms need separate review; do not equate Cloud allowances with local workspace limits.
- trade-off-summary: Compare locally available notes and organized content in the installed native workspace. Complete offline availability of all Cloud pages and attachments is not established by this review. Hosted Notion zip import needs connectivity and post-import review; advanced ecosystem integrations and view parity are not guaranteed. Personal Cloud has storage/upload/history limits; Pro is per workspace member.

Scope: Personal offline note and object organization only. Locally available content in the installed native workspace after setup. Cloud synchronization and the documented hosted Notion import need connectivity; complete offline caching of Cloud pages and attachments is not established. No guarantee of full Notion feature, team or migration parity.
