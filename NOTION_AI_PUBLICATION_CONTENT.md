# PR5.20 — No-required-AI route content review

Publication decision: pending. This is the concrete content proposed for the fourth route; review before owner approval.

## Public title

Notion Alternatives Without AI

## Public introduction

Personal offline notes and locally available organized content in installed native apps, without activating optional AI tools. AFFiNE, AppFlowy and Anytype offer overlapping personal workflows; this is not full Notion parity, an AI-free interface promise, or a privacy/processing guarantee. Optional AI and agent integrations have separate setup and data-handling terms.

## Comparison and recommendation notes

### AFFiNE

Constraint fit: AI Optional — verified 2026-10-12.

Recommendation note: Native personal local documents and organization without invoking AI. AFFiNE AI is a separate Cloud/sign-in feature; optional AI UI and services remain available. No promise that all AI controls disappear.

Pricing: Free local editor and Cloud Basic; paid Cloud plans, an AI add-on and a one-time Believer offer have separate terms. The editor is MIT-licensed; the EE backend has separate authorization requirements for modification, compilation or redistribution. Check current plan prices and limits.

Trade-offs: Native desktop local content is the offline comparison scope. Desktop and mobile feature coverage differs; Cloud sync and collaboration require connectivity. Notion HTML/Markdown import is supported but not all features map one-to-one; review converted content. Editor and EE backend licensing differ.

### AppFlowy

Constraint fit: AI Optional — verified 2026-10-12.

Recommendation note: Native personal notes and workspace organization using documented opt-in Smart Write/Edit. Opt-in AI does not establish an AI-free interface, no AI indexing in every mode, or no third-party processing when AI is enabled.

Pricing: Free Personal Cloud plan with storage, upload and history limits; Pro is a renewing subscription billed per workspace member. Cloud plans and self-hosted terms need separate review; do not equate Cloud allowances with local workspace limits.

Trade-offs: Compare locally available notes and organized content in the installed native workspace. Complete offline availability of all Cloud pages and attachments is not established by this review. Hosted Notion zip import needs connectivity and post-import review; advanced ecosystem integrations and view parity are not guaranteed. Personal Cloud has storage/upload/history limits; Pro is per workspace member.

### Anytype

Constraint fit: AI Optional — verified 2026-10-12.

Recommendation note: Native personal notes/object organization without installing or authorizing an AI agent. Official policy allows no AI; the agent toolkit requires separate setup and an API key. Experimental plans are not shipped feature guarantees; optional integrations can expose data to the chosen agent.

Pricing: A Free tier and paid membership plans are available. Paid plans expand remote storage, shared-channel and ANY ID entitlements. Check current plan prices and limits; self-hosted configurations and renewals have separate terms.

Trade-offs: Scope is personal notes and objects stored on the device, not full Notion parity. Normal local-first mode works offline and syncs when connected. Optional local-only mode is experimental and requires manual backups, with multi-device sync limited to the local network. Notion imports can lose feature semantics, links or files and need review.

## Approval boundary

Approve only this route and these three reviewed members, all with zero novelty score. The scope is installed native personal note/object organization without activating optional AI. No promise of an AI-free interface, full Notion parity, no AI processing in every mode, or privacy protection. Optional AI/agent setup has separate terms. Existing products, prices, claims and other routes are not rewritten.
