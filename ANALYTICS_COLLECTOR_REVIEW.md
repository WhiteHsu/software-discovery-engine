The collector requires exact configured/request Origin and same-origin Fetch Metadata where present; unknown/missing origin is denied. JSON UTF8 body capped at16KiB while streaming with2-second deadline; compressed bodies/unsupported types rejected. Early structural validation limits1..20 same-session/page/path events, preventing multi-route graph lookup fanout. DNT1/GPC1 skips collection. Only production Vercel's x-vercel-forwarded-for is used for the server daily HMAC quota key, with strict single-IP parsing and IPv6 canonicalization. Raw IP and bodies are not logged or returned. Official header reference: https://vercel.com/docs/headers/request-headers (reviewed2026-10-19; x-vercel-forwarded-for is the platform-specific equivalent when proxy layering may overwrite ordinary x-forwarded-for). Other hosts, proxy topology changes and development are fail-closed, not generic trusted-header support.

Before graph lookup, bounded in-memory admission allows at most30 requests/key/minute and300 per instance/minute. It is local load shedding, not durable global abuse control; cold starts/multiple instances reset or split this budget. Private RPC durable120-events/key/minute and1000 global limits remain authoritative for persistence. Spoofed non-browser requests can supply an Origin; these controls do not prove a human visit or remove bot/fraud concerns. Publication context is loaded through existing public getEscape/getProduct.
